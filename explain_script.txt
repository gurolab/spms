1) Opening Script (Present your slide)
====================================================================

Good day, everyone. Thank you for this opportunity to present my capstone project,
the Supply Management System, or SMS, for Cotabato State University.

Based on Chapter I of the study, the main problem is that manual and Excel-based
processing causes delays, retrieval difficulty, and inventory inaccuracies.

SMS addresses this by digitizing end-to-end operations:
1. Requesting supplies/property
2. Receiving and issuing items
3. Inventory and stock monitoring
4. Property accountability tracking
5. Compliance report generation
6. Audit trail recording

The system is role-based so each office sees only what is needed for their
function while preserving one centralized institutional record.


====================================================================
2) Simple Story (Slides)
====================================================================

Think of SMS as one secure university service desk with six windows:

- Window 1: Employee files requests.
- Window 2: Supply Officer receives deliveries and issues supplies.
- Window 3: Inventory Officer watches stock health and reorder risks.
- Window 4: Property Custodian tracks equipment accountability.
- Window 5: Auditor checks compliance reports and activity logs.
- Window 6: System Admin manages users, roles, and governance.


Illustration of flow:

Department/Office Request
        |
        v
RIS Processing + Issuance (RSMI)
        |
        +--> Stock cards and supply ledger are updated
        |
        v
For non-consumables:
ICS/PAR -> Property Card -> Transfer/Status tracking
        |
        v
Audit Logs + Compliance Reports (RPCI/RPCPPE/IIRUP)

A) EMPLOYEE ROLE SCRIPT
--------------------------------------------------------------------

Screen path:
- Dashboard: employee/dashboard.php
- Request page: employee/requisition.php
- Request details: employee/request-details.php
- Status page: employee/acknowledgment.php

What to say:
1. "As an employee from a requesting office, I can create a request directly in SMS."
2. "I encode requisition date, fund cluster, purpose, and remarks, then save."
3. "I open the request and add line items with quantities."
4. "While status is Requested, I can still edit details. Once processing starts, it is locked for integrity."

- "This supports on-time request processing and transparent request tracking."

- "Role-based access control limits module visibility by function."
- "Authentication events and operational actions are logged in audit trails."
- "CSRF tokens are enforced for POST-based actions."
